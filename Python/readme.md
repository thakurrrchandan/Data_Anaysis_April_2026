# Stage 2: Exploratory Data Analysis (Python)

## Overview
This folder contains the programmatic Exploratory Data Analysis (EDA) stage of the project. Using **Python** (`pandas`, `numpy`, and `matplotlib`), the cleaned dataset was aggregated to calculate core business metrics, uncover statistical correlations, and generate static visualizations.

## Files Included
* `Python Analysis code.ipynb`: A Jupyter Notebook containing all python code for data manipulation, metric calculations, and charting.
* `metrics.docx` / `metrics_2.docx`: Documentation outlining the core business questions and KPIs targeted during this analysis.

## Key Analytical Tasks
* **Data Aggregation (`pandas`):** Calculated high-level metrics including Total Revenue (130M+), Total Orders, and Average Order Value.
* **Segmented Analysis:** Grouped data to extract insights on City-Level Performance, Product Popularity, and Customer Purchasing Behavior.
* **Correlation:** Analyzed the statistical correlation between Price, Quantity, and Total Amount.
* **Static Visualization (`matplotlib`):** Programmatically generated charts to spot trends, including:
  * Monthly Revenue Trends
  * Revenue by City (Horizontal Bar Charts)
  * Top Products by Revenue
