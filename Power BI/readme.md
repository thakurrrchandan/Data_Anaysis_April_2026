# Stage 4: Interactive Dashboarding (Power BI)

## Overview
This folder contains the final visual storytelling and business intelligence phase of the project. **Microsoft Power BI** was used to connect to the cleaned data model and build an interactive, dynamic dashboard for stakeholder reporting.

## Files Included
* `dashboard.pbix`: The final Power BI dashboard file containing the data model, visual reports, and interactive slicers.

## Key Dashboard Features
* **Dynamic Filtering:** Allows users to slice data by Year, Quarter, Month, or City to see real-time updates across all charts.
* **KPI Tracking:** High-level scorecard visuals tracking Total Orders, Total Revenue, and Average Order Value at a glance.
* **Visual Insights:** 
  * Line charts mapping Monthly Revenue Trends over time.
  * Bar charts comparing Revenue by City and Top Products.
  * Category and Payment Method breakdowns.
